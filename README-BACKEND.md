
# K.S SOCIAL Backend

## Requirements
- Node.js 20 or newer
- npm
- Supabase project

## Install dependencies
npm install

## Configure environment
Copy .env.example to .env.

Set the correct ALLOWED_ORIGIN for the deployed frontend.

## Start locally
npm start

## Health check
Open:
http://localhost:3000/api/status

## Database
Run database.sql in the Supabase SQL Editor.

Never commit .env files or secret keys.
