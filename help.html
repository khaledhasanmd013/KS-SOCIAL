❓ Frequently Asked Questions

১. K.S SOCIAL-এ কীভাবে অ্যাকাউন্ট খুলব?

অনুমোদিত Invitation Code এবং প্রয়োজনীয় তথ্য দিয়ে Registration পেজ থেকে অ্যাকাউন্ট খোলার ব্যবস্থা থাকবে।

২. Invitation Code কোথায় পাব?

অনুমোদিত Owner বা Admin-এর কাছ থেকে Invitation Code পাওয়ার ব্যবস্থা থাকবে।

৩. পাসওয়ার্ড ভুলে গেলে কী করব?

ভবিষ্যতে নিরাপদ Password Reset সুবিধার মাধ্যমে পাসওয়ার্ড পরিবর্তন করা যাবে।

৪. কীভাবে Friend Request পাঠাব?

Friends পেজে গিয়ে সদস্য খুঁজে Friend Request পাঠানোর ব্যবস্থা থাকবে।

৫. কীভাবে কাউকে Block করব?

ভবিষ্যতে Profile বা Privacy Settings থেকে Block করার সুবিধা যুক্ত করা হবে।

৬. Video Meeting কি এখন চালু আছে?

বর্তমানে এটি শুধু ডিজাইন। বাস্তব ভিডিও মিটিং চালু করতে আলাদা প্রযুক্তিগত ব্যবস্থা প্রয়োজন।
